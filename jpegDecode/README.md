# rocPyJpegDecode

Python bindings, samples, and tests for the ROCm rocJPEG image decoding library.
This component can be configured, built, installed, and tested independently.

- [Prerequisites](../docs/install/rocPyDecode-prerequisites.rst)
- [Build from source](../docs/install/rocPyDecode-cmake-install.rst)
- [Installation and installed-package tests](../docs/install/rocPyDecode-install.rst)
- [API reference](../docs/reference/rocPyJPEGDecode-api.rst)
- [Samples](../docs/tutorials/jpeg-samples.md)

For a standalone build, run the documented CMake commands from this directory
and install only this component's SDK dependencies. If using a standalone copy,
refer to the [published documentation](https://rocm.docs.amd.com/projects/rocPyDecode/en/latest/).
